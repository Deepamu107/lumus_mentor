# lumus_mentor
A Python and Flask-based adaptive learning platform that analyzes student performance and learning patterns to deliver personalized explanations, interactive quizzes, and performance insights for an improved learning experience.
# Adaptive Learning System

An interactive web-based learning platform built using Python and Flask. It analyzes students' quiz answers, time taken, and hint usage to understand their learning patterns.

Based on the student's performance, the system provides suitable explanations such as step-by-step solutions, real-life examples, and reasoning-based explanations to make learning easier.

### Features
- Interactive quizzes.
- Identifies students' learning patterns.
- Provides personalized explanations.
- Tracks quiz performance and accuracy.
- Displays final results and learning style.

### Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

### Objective
To make learning easier and more effective by providing explanations based on individual student learning patterns.
